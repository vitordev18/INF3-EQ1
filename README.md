## 📋 Overview

This is a cross-platform mobile application built with **Flutter** to assist the Environmental Police during **on-site inspections of timber companies**. The goal is to replace paper forms and scattered records with a single mobile tool that officers can use in the field to register inspections, document findings, and keep everything organized.

The project was developed as a **capstone (TCC)** by a team, applying mobile development concepts to a real, socially relevant problem.

---

## ✨ Features

<!-- Adjust this list to match exactly what the app implements. -->

- 📝 Register inspections carried out in the field
- 🏭 Record inspected company data
- ✅ Compliance checklists during the inspection
- 📸 Attach photos as inspection evidence
- 📍 Capture the inspection location
- 🗂️ Browse the history of past inspections

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- An Android/iOS emulator or a physical device

### Installation

```bash
# Clone the repository
git clone https://github.com/vitordev18/INF3-EQ1.git
cd INF3-EQ1/src/app

# Install dependencies
flutter pub get

# Run the app
flutter run
```
