# 🌳 Fiscalização Ambiental — Timber Inspection App

> **Aplicativo mobile para apoiar a Polícia Ambiental na fiscalização de madeireiras em campo**

---

## 📌 Sobre o Projeto

- **Problema identificado:** As fiscalizações de campo em madeireiras ainda dependem de formulários em papel e registros dispersos, o que dificulta a organização, o armazenamento e a consulta posterior das informações coletadas pelos policiais.
- **Solução proposta:** Um aplicativo mobile multiplataforma, desenvolvido em Flutter, que permite aos policiais ambientais registrar inspeções em campo, cadastrar dados das empresas fiscalizadas, aplicar checklists de conformidade, anexar fotos como evidência e capturar a localização da inspeção — tudo centralizado em um único lugar, substituindo os formulários em papel.
- **Público-alvo:** Policiais da Polícia Ambiental responsáveis pela fiscalização de madeireiras.

> 🎓 Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) em equipe, aplicando conceitos de desenvolvimento mobile a um problema real e socialmente relevante.

---

## ✨ Funcionalidades

- 📝 Registro de inspeções realizadas em campo
- 🏭 Cadastro de dados da empresa fiscalizada
- ✅ Checklists de conformidade durante a inspeção
- 📸 Anexo de fotos como evidência da inspeção
- 📍 Captura da localização da inspeção
- 🗂️ Histórico de inspeções anteriores

> _Algumas funcionalidades podem estar em desenvolvimento — projeto com finalidade acadêmica._

## ⚙️ Como Executar Localmente

### Pré-requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Um emulador Android/iOS ou um dispositivo físico

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/vitordev18/INF3-EQ1.git
cd INF3-EQ1/src/app

# 2. Instale as dependências
flutter pub get

# 3. Execute o aplicativo
flutter run
```
